These are the actual temporary public-door drivers used for the candidate screenshots. They were kept out of the product commits and removed from the clone after the captures. The normal integration assertions live in the committed tests listed by REPORT.md.

To inspect or replay, console-runtime.mjs corresponds to tests/plain-monitor-harness.mjs, console-driver.mjs to tests/plain-monitor-probe.mjs, and snapshot-driver.mjs to tests/plain-snapshot-proof.mjs. The runtime is the repository's existing browser-suites runtime with the selected console proof substituted and the unrelated recovery suite omitted. It retains the original owned-process cleanup. The output path is this task's packet directory. Both drivers use native sign-in and public APIs; only network edges and the controlled target are fixtures. The console proof starts the real private runner. The snapshot proof submits a real signed HTTP probe result.
